# Git GUI

Git을 잘 모르는 사람도 바뀐 내용을 확인하고, 저장(커밋)하고, 온라인에 올리고(푸시), 예전 상태로 되돌릴 수 있도록 돕는 데스크톱 Git 클라이언트입니다.

## 현재 상태

- **데모 모드**: 가상의 프로젝트로 저장 → 비밀 정보 경고 → 올리기 → 되돌리기 흐름을 체험할 수 있는 클릭형 프로토타입
- **실제 저장소 모드** (데스크톱 앱): 폴더를 열어 실제 저장소를 다룸
  - 상태 확인: 갈래, 온라인과의 차이(ahead/behind), 바뀐 파일 (`git status`)
  - 저장 기록 그래프: 모든 갈래·태그·온라인 갈래를 레인별 색으로 표시 (`git log`)
    - 점에 마우스를 올리면 요약 카드: 여기서 일어난 일(합치기·갈라짐·첫 저장), 몇 번째 저장 지점인지, 바뀐 파일과 줄 수
  - 커밋: 체크한 파일만 저장 지점으로 기록. `.env`·개인 키 같은 비밀 정보 파일은 기본으로 빼고, 포함하려 하면 경고
  - 올리기(push): 아직 안 올린 저장 지점 목록, 모두 올리기 / 특정 저장 지점까지 올리기, 처음 올리는 갈래는 온라인에 새로 만들고 연결
    - 올라갈 저장 지점에 비밀 정보 파일이 있으면 한 번 더 확인
    - GitHub 로그인은 Git Credential Manager 의 로그인 창을 사용
    - 거절(온라인에 새 저장 지점 있음)·로그인 실패·네트워크 오류 등을 쉬운 말로 안내
  - 받아오기(pull): 받아올 저장 지점(누가 무엇을 올렸는지) 미리보기 후 받아오기
    - 내 쪽에 새 저장 지점이 없으면 그대로 따라가고(fast-forward), 양쪽 다 있으면 합침(merge)
    - 충돌이 나면 받아오기를 자동으로 취소하고 원래 상태로 되돌림 + 충돌 파일 안내 → [충돌 해결하기]
    - 저장 안 한 변경과 겹치면 아무것도 바꾸지 않고 "먼저 커밋" 안내
    - 저장소를 열 때·창으로 돌아올 때 온라인 새 저장 지점을 조용히 확인 (로그인 창 없이)
  - 충돌 해결 화면: Git 의 `<<<<<<<` `=======` `>>>>>>>` 기호를 직접 고치는 대신
    - 충돌 부분을 "내 것 / 온라인 것" 카드로 나란히 보여주고 [내 것] [온라인 것] [둘 다] 버튼으로 선택
    - 기호가 남은 채 저장하는 것을 막음, "원래 Git 표시 보기"로 기호의 의미도 설명
    - 한쪽에서 지운 파일·이미지는 파일 전체로 선택
    - 파일별 저장 → 모두 끝나면 [합치기 완료], 언제든 [합치기 취소]로 받아오기 전 상태로
  - 다른 프로그램에서 파일을 바꾸고 창으로 돌아오면 자동으로 다시 읽음
  - 실행할 때 폴더 경로를 주면 그 저장소를 바로 엶 (`git-hani.exe D:\프로젝트`)
  - 되돌리기: 그래프에서 저장 지점을 골라 [이 상태로 되돌리기]
    - 기록을 지우지 않고, 그 상태 그대로의 새 저장 지점을 하나 더 만듦 (온라인에 올린 기록도 안전)
    - 저장 안 한 변경과 새 파일은 먼저 `backup/…` 갈래("되돌리기 전 백업")에 보관 → 그래프에서 골라 되살리기
    - 되돌리기 전에 되살아나는/지워지는/바뀌는 파일 미리보기
    - [변경 모두 취소]: 마지막 저장 상태로 (AI 가 망쳐 놨을 때)
    - `.gitignore` 에 있는 파일(.env, node_modules 등)은 건드리지 않음

## 기술 구성

| 영역 | 사용 기술 |
|---|---|
| 화면 | React, TypeScript, Vite, Tailwind CSS |
| 데스크톱 | Tauri 2 (Rust) |
| Git | PC에 설치된 git CLI 실행 |

## 실행 방법

필요한 것: Node.js, Rust(rustup), Git, Windows의 경우 Visual Studio C++ Build Tools

```bash
npm install

# 웹 브라우저에서 데모만 보기
npm run dev

# 데스크톱 앱으로 실행 (실제 저장소 열기 가능)
npm run desktop

# 실행 파일 빌드
npm run tauri build
```

Rust 단위 테스트:

```bash
cd src-tauri
cargo test
```

## 폴더 구조

```
src/                   화면 (React)
  App.tsx              전체 레이아웃, 데모/실제 모드 전환
  store.ts             데모 시나리오 상태와 터미널 명령 해석
  git.ts               Rust 명령 호출, 비밀 파일 판별
  graphLayout.ts       저장 기록 그래프의 레인 배치
  graphInsights.ts     그래프 모양에서 저장 지점별 설명(합치기·갈라짐·순서) 만들기
  components/          화면 구성 요소
src-tauri/             데스크톱 앱 (Rust)
  src/git.rs           git status / log / commit / push / pull / 충돌 해결 / 되돌리기 실행과 결과 해석, 테스트
  src/commands.rs      화면에서 부르는 명령 (별도 스레드에서 실행해 창이 멈추지 않게)
  src/lib.rs           Tauri 명령 등록
```
